\title{5i}{1}

# NAME
5i – an ARM program run on another machine

# SYNOPSIS
**5i**
[ **-t** ]
[ **-s** ]
[ **-y** ]
*program*
[ *arg* ... ]

# DESCRIPTION
*5i* runs *program*, an ARM executable, as its system would: a
Linux ELF file for arm or arm64, or a Plan 9 *a.out* for arm. The
instructions are interpreted one by one, the system calls done by
the host, and the program's output and exit status are its own. A
file that is a script is given to the host to run.

**-t**
:    Each instruction on the standard error, before it is run: its
     address and the instruction disassembled.

**-s**
:    At the end, the instructions counted, the time and the speed.

**-y**
:    Each system call on the standard error: its number, its
     arguments and its result.

**-h**
:    How, by examples.

# EXAMPLES
A program of goken's, assembled and linked by ix's tools, then run:

```
asm -m 5 hello_linux_arm.s
ld -m 5 -E _start -o hello hello_linux_arm.5
5i hello
```

# BUGS
The instructions are a subset: programs compiled by gcc against
glibc use SIMD and more, and are not run.
