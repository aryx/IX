\title{mtime}{1}{files}

# NAME
mtime – when a file was last written

# SYNOPSIS
**mtime**
*file* ...

# DESCRIPTION
*Mtime* writes, for each *file*, the seconds since 1970 when it was
last written, and its name: a script's question, and *mk*'s.

# EXAMPLES
```
mtime mkfile
```
